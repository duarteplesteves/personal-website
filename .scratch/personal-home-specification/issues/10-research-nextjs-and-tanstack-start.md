# Research Next.js and TanStack Start for the personal home

## Question

According to current official documentation and ecosystem evidence, how do Next.js and TanStack Start compare for a static-first bilingual content site with a growing Library, minimal client JavaScript, strong metadata and image handling, repository content, excellent performance and accessibility, simple deployment, and a worthwhile but finishable learning experience?

## Answer

Current evidence conditionally favors Next.js for finishability, static-first Server Components, metadata conventions, documented accessibility behavior, and lower maturity risk. TanStack Start remains officially a release candidate and ships a client-hydration model, but offers meaningful learning value through typed routes, loaders, and URL search state that could become relevant to the Library. Neither candidate decides bilingual content correctness or maintenance workflow. A representative static bilingual slice should be built in both before the final choice; if measured results are close, choose Next.js unless TanStack’s learning and router benefits prove concrete enough to justify its risk.
