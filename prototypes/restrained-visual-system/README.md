# PROTOTYPE — restrained visual system

Three structurally different versions of Home, switchable with `?variant=A`, `B`, or `C`, on the throwaway `/prototype/restrained-visual-system` surface represented by this static folder.

## Run

From the repository root:

```sh
npm run prototype:visual
```

Open <http://localhost:4173/?variant=A&lang=en>.

- Use the floating arrows or keyboard Left/Right to switch variants.
- Use **Português / English** in the page header to inspect equivalent copy and text expansion.
- The locale query parameter is only a static-prototype stand-in for the already-decided `/en` and `/pt` route prefixes.
- Names of Work candidates and Setup/tools come from the planning map. Book titles and descriptive copy are representative prototype content, not publication claims.

## What to judge

Which composition—or combination of parts—best makes Home feel like a calm personal document rather than a résumé, project gallery, or dashboard? Specifically compare hierarchy, scanning rhythm, density, the Home Library preview, and how much visual personality survives the restrained system.

This code is intentionally throwaway and must not be promoted directly into production.
